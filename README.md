# Questões+ | Ambiente de testes do importador

Este repositório é exclusivo para testar o importador de provas. Ele não altera nem publica a versão principal do Questões+.

## Abrir a ferramenta
Depois de ativar o GitHub Pages em **Settings → Pages → Deploy from a branch → main → /(root)**, a página inicial encaminha para `admin/importador.html`.

## Arquivos
- `admin/importador.html`: interface do importador.
- `admin/importador.css`: estilos.
- `admin/importador.js`: leitura de PDFs e geração de pacote JSON.
- `admin/LEIA-ME.md`: instruções, fluxo e limitações.

## Avisos
A primeira versão lê PDFs com texto selecionável. Não possui OCR para PDFs escaneados. A extração do gabarito é apenas uma sugestão e exige conferência com o gabarito oficial definitivo. A ferramenta não publica automaticamente o pacote no catálogo.

A reprodução integral de questões depende de autorização ou de fundamento jurídico válido. A existência de um PDF público não significa, por si só, autorização para republicar seu conteúdo.
